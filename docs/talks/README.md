# Technical Talk Appendices

The detailed PDF slide decks for several MI350/GFX950 features are intentionally
omitted from this initial open-source release while they go through a separate
publication review.

Planned appendices include:

- Buffer operations in Triton
- Direct-to-LDS data movement
- `ds_read_tr` hardware-assisted layout conversion

The tutorials do not require these PDFs to be useful. The core concepts needed
to follow the kernels are summarized directly in the relevant README files. Once
the slide decks are cleared for publication, they can be added back as technical
appendices in a follow-up release.
